NYC Hydrant Analysis Map

Project Description

This interactive web map visualizes fire hydrant density and count across New York City neighborhoods.
This project was completed as part of the Spatial Lab Modern GIS Accelerator and demonstrates deployment of vector tile datasets using PMTiles and MapLibre GL JS through GitHub Pages.

Data Sources

  • New York City fire hydrant inventory
  • NYC neighborhood boundaries
  • OpenStreetMap basemap data

Methodology

  1. Aggregate hydrants by neighborhood.
  2. Calculate hydrant density per square kilometer.
  3. Create vector tiles using PMTiles.
  4. Display the data using MapLibre GL JS.

Technology Stack

  • MapLibre GL JS
  • PMTiles
  • GitHub Pages
  • HTML, CSS, and JavaScript
